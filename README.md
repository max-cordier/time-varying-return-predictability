# Shifting drivers of stock returns: machine learning evidence on time-varying predictability

Master's thesis code (Master of Business Administration, Financial Analysis, KU Leuven, 2025–2026).
Authors: Max Cordier & Robbe Denaux. Promoter: Prof. Dr. Chunjie Wang.

**Research question:** How do the top firm-level characteristics that machine learning identifies as predictors of stock returns vary over time?

ElasticNet, Random Forest and a feed-forward Neural Network are estimated on a panel of US stocks (1970–2024) using rolling 10-year training windows with per-decade hyperparameter tuning. Because the windows roll, each prediction year gets its own feature-importance ranking, so predictor importance can be tracked decade by decade instead of averaged over the full sample.

**Main finding:** predictor importance depends on the regime. Size-related characteristics are top predictors in every decade, while the secondary tier shifts: momentum in the 1980s, liquidity through the 2000s, and accounting fundamentals (including a partial recovery of book-to-market) in the 2010s–2020s.

The full thesis is in [`thesis/Cordier_Max_MastersThesis.pdf`](thesis/Cordier_Max_MastersThesis.pdf) and the poster is in [`thesis/Poster.pdf`](thesis/Poster.pdf).

```
data_clean/   (empty) generated by the cleaning scripts
```

## Data

The raw data comes from **CRSP** and **Compustat** through WRDS. It's licensed and can't be redistributed, so it isn't included here. Stock-level prediction files are also left out because they contain CRSP returns. To reproduce the results, export the following into `data_raw/`:

| File | Source |
|---|---|
| `CRSP Monthly Stock File.csv` | CRSP monthly stock file (WRDS) |
| `CRSP Daily Stock File.csv` | CRSP daily stock file (WRDS) |
| `Compustat Annual Fundamentals.csv` | Compustat North America annual fundamentals (WRDS) |
| `ff_factors_monthly.csv` | Fama–French monthly factors ([Kenneth French data library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)) |

## Running

The scripts use relative paths (`../data_raw`, `../output`), so run them from inside `scripts/`:

```bash
pip install -r requirements.txt
cd scripts

# 1. Data preparation
python "csv_to_parquet(daily).py"
python clean_crsp_monthly.py
python clean_crsp_daily.py
python merge_crsp.py
python clean_compustat.py
python merge_ccm.py
python data_quality_validation.py

# 2. Models (rolling 10-year windows)
python elasticnet_rolling.py
python elasticnet_alpha_grid.py
python random_forest_rolling.py
python neural_network_rolling.py

# 3. Figures
python regenerate_figures.py
python combined_figures.py
python methodology_timeline.py
```
